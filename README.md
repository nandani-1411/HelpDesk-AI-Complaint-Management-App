## 🎯 Key Features
- **Student Portal**:
  - Raise complaints (Scholarship, Placement, Infrastructure, Academics, Admin).
  - Live photo capture via **Camera**.
  - Auto-tagging of campus coordinates via **GPS**.
  - Real-time status tracking (`Pending`, `In Progress`, `Resolved`).
- **AI Engine**:
  - Auto-categorizes complaint text based on grievance keywords.
  - Generates instant suggested answers for common student queries.
- **Admin / Staff Portal**:
  - Manage incoming complaints.
  - Assign priority, update status, and communicate replies back to students.
